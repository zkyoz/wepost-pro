# Manuel — Annotations de média

## Créer une annotation

Depuis les médias d’une publication, ouvrir « Annotations » sur l’image ou la vidéo concernée. Choisir un point ou un rectangle, puis utiliser la souris sur la visionneuse ou saisir les coordonnées en pourcentage dans le formulaire. Le commentaire est obligatoire : il constitue la description accessible et la source de vérité de l’annotation.

Après validation, le marqueur numéroté apparaît sur le média et dans la liste chronologique. Activer le marqueur place le focus sur son entrée textuelle. Un client, un membre agence ou un administrateur ne peut annoter que les publications d’un projet auquel il a accès.

## Modifier, supprimer et modérer

L’auteur peut modifier le texte ou supprimer logiquement son annotation. L’administrateur peut modérer une annotation ; cette action est journalisée. La suppression conserve une trace textuelle pour la chronologie sans maintenir le marqueur actif.

## Versions et commentaires

L’annotation est liée à la version courante de la publication et à l’empreinte immuable du média. Après modification de la publication, les anciennes annotations restent dans la liste avec la mention « Historique — version N » mais ne sont plus superposées au média. Une annotation peut être liée à un commentaire de la même publication ; le fil de discussion affiche alors un lien vers son numéro.

Les médias restent privés : la visionneuse utilise une URL de lecture signée à durée courte. En cas d’absence de média ou de droits, ne jamais copier une clé de stockage ou une URL R2 dans un commentaire.
