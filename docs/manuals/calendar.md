# Manuel du calendrier éditorial

## Consulter

Le lien « Calendrier » est disponible aux trois rôles. Choisir Mois, Semaine ou Liste, puis filtrer par projet, client, réseau et statut. La vue Liste contient les mêmes informations dans un ordre linéaire accessible. Les publications sans date apparaissent dans une section dédiée.

Le fuseau d’affichage peut être changé. Les données restent stockées en UTC ; le libellé visible est recalculé dans le fuseau choisi.

## Déplacer

Une agence ou un administrateur ouvre « Déplacer … », saisit la date/heure locale et le fuseau, puis enregistre. Le statut ne devient pas automatiquement `scheduled`. Une approbation existante est conservée tant que le contenu n’est pas modifié.

Si une autre session a modifié la publication, un conflit est affiché et le calendrier est rechargé. Les clients ne disposent d’aucun contrôle de déplacement.

## Limites

Une requête est limitée à 366 jours et 100 résultats par page. Utiliser les filtres ou la vue liste si le message de volume apparaît. Les statuts `publishing`, `published` et `archived` ne peuvent plus être déplacés.
