# Tâche 21 — Supervision système

Implémenter liveness/readiness, logs corrélés, heartbeat worker, métriques API et BullMQ, page admin protégée, Uptime Kuma, alertes, runbook incident et smoke tests post-déploiement. Ne pas stocker les métriques brutes dans PostgreSQL. Les détails et actions de relance sont réservés à l’administrateur, expurgés et audités. Produire tests, recette, sécurité, accessibilité et preuves sans inventer les résultats de préproduction.
